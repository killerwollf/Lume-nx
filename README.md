# LUME NX — Phase 1

Independent frontend prototype. The previous Lume project is untouched.

## Stack
Next.js 16 App Router APIs, React 19, TypeScript strict, Tailwind 4, shadcn/ui. The Sites runtime builds the Next-compatible application with Vinext for Cloudflare Workers.

## Routes
/ /explore /create /create/image /create/video /create/audio /edit /assets /projects /history /models /adult /adult/image /adult/video
Additional: /community /pricing /workflows /collections /shared

## Main files
- app/**/page.tsx: explicit entries for each route
- features/studio/StudioApp.tsx: layout and route views
- features/studio/Hero.tsx: cinematic carousel
- features/studio/Composer.tsx: prompt and contextual choices
- features/studio/Media.tsx: gallery and audio
- features/studio/VideoPreview.tsx: viewport-aware video
- features/studio/useStudio.ts: local persistence and job simulation
- registry/models.ts: central model registry
- core/types.ts: domain contracts and feature flags
- core/intent.ts: bilingual heuristic intent router
- providers/mock.ts: ProviderAdapter and mock implementation
- app/globals.css: design tokens and responsive styles

## Navigation fix
Each page has its own route and receives its identity from its page entry. Menus use ordinary links so the destination loads independently of client-router state. Draft prompts are carried in sessionStorage.

## Functional
Navigation, carousel with manual controls and reduced motion, rotating suggestions, searchable model catalog, category filtering, local job queue/progress/cancel/success, asset previews/rename/favorite/delete, session uploads, adult gate, local persistence for generated sample records, project sample views, mock credit estimates. A prompt containing [fail] simulates a failed job. Public collection is restricted to demo records; private adult records are excluded from public views.

## Deliberately mocked
No model providers, AI generation, real billing, authentication, cloud upload, permanent file storage, real model capabilities/prices, editing operations, voice cloning, 3D rendering, team sharing, security-grade age verification. Creative settings change UI state but do not modify sample output. Download is a placeholder. New projects exist only in the current session. Uploaded files use session object URLs, and are omitted from localStorage. Adult gate is local UI state, not server authorization.

## Phase 2
Add authenticated API client, server-side policy/access controls, validated registry import, a single provider adapter, durable jobs and object storage. Integrate billing only after generation and cancellation costs are validated. Keep the existing Lume separately addressable during migration.
